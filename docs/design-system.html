03 — the hero encodingKinesiaScore, diverging

The 7-point diary scale maps exactly onto a 7-step diverging ramp. Zero is the good state and both ends are impairment in opposite directions — cool is too little movement, warm is too much. Any ramp that runs good→bad in one direction is factually wrong about the disease.

Why the midpoint is not invisible

“Good kinesia” is 57% of all labelled hours — the most common state on a good day. A near-surface neutral would make a healthy day look like missing data. Both midpoints are stepped to clear 2.05:1, so a good hour reads as a calm present band. It stays neutral rather than green: hue at a diverging midpoint makes the centre read as a third category.

06 — the instrumentInteraction

The UI is not a viewer, it is an instrument. A judge should be able to take the mouse and interrogate it — that is what separates this from every unfalsifiable demo in the room. Build in this order; each is independently demo-able.

1 · Reveal wipe

Draggable handle sweeps left→right. Truth is clipped to the swept region so it uncovers rather than fades. Running error readout moves with it. R auto-sweeps in 1.6 s.

2 · Scrub the day

Crosshair + tooltip naming the evidence tier in words. Every linked panel updates together.

3 · Posterior inspector

Click an hour → the full 7-way distribution, MAP marked, 90% interval bracketed. Confident = a spike; abstaining = nearly flat. That contrast is the argument.

4 · Sensor toggles

Drop a wrist: band widens 400 ms, abstention holes punch in staggered 20 ms, metrics count rather than jump. Two clicks, whole uncertainty claim.

5 · Evidence layers

Toggle observed / reported / inferred. Turning inferred off should leave the screen sparse — that emptiness is the honest picture of how little was measured.

Interaction rules

Hit targets ≥44px, always larger than the mark. Filters in one row above the charts, never over data. Nothing animates on hover except the crosshair and tooltip — data must not appear to move when you point at it. Every state is in the URL, so you can jump back to any moment when a question sends you backwards. Loading is a skeleton in the final layout, never a spinner. prefers-reduced-motion turns the wipe into a toggle: it still works, it just stops moving.

07 — rulesChart & projector

Never

Two y-axes. A number on every point. Colour by rank instead of entity. A rainbow ramp. Hue at a diverging midpoint. Gradients or shadows on data marks. Hairlines under 1.5px.

Always

Legend for ≥2 series and direct labels. Uncertainty as a filled band, not error bars. Hover crosshair + tooltip that names the evidence tier in words. A table view. Recessive hairline grid.

Projector — 3 metres

Minimum 16px type on screen, 14px mono for axis labels. Screenshot and desaturate before you ship — if the reveal still reads, the encoding is sound. Set browser zoom before you start and never touch it mid-demo.
